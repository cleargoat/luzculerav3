LightUtils - Forge 1.20.1
Compilar: instala JDK 17 y ejecuta  ./gradlew build  (usa el wrapper del MDK de Forge 1.20.1)
El .jar queda en build/libs/. Ponlo en la carpeta mods.

Comandos (requiere OP nivel 2):
  /lightutils add <color> <intensidad 0-15> <radio 1-64> <tag>
  /lightutils clear <tag>
Color: rojo, verde, azul, amarillo, naranja, morado, rosa, cian, blanco o hex (ej: ff8800)
